# 可选家庭角色

角色是本地显示素材，不涉及登录、人脸识别或上传照片。共享组件为 `app/components/family-portrait/family-portrait.vue`；其读取的固定文件名由 `app/family/portraits.mjs` 提供。

## 使用位置

| 位置 | 角色与行为 |
| --- | --- |
| 首页 | 孩子与父母组成欢迎插图，不代替家长说话 |
| 跳一跳 | 孩子全身像随原有位置、蓄力压缩和跳跃移动；可见鞋底对齐岛面 |
| 消消乐 | 五种表情替换棋子插图，保留五种底色、水果标记及相同标记的收集目标 |
| 五子棋 | 观察说明卡中的思考形象，不遮住棋盘或暗示答案 |
| 英语 | 开始与完成页面，练习题内不增加装饰 |
| 实验室 | 发现说明与完成报告，不在尚未揭示的结论处提前显示 |
| 成长小花园 | 鼓励形象，不用家长失望、责备表情惩罚错误 |

角色只改变显示，不更改关卡、奖励、碰撞、题目答案或已有本地记录。

## 本地素材包

目录 `app/static/private-family/` 已列入 `.gitignore`。透明 PNG 使用以下名称：

| 文件 | 用途 |
| --- | --- |
| ready-v1.png | 自信的准备状态 |
| thinking-v1.png | 思考 |
| discovery-v1.png | 发现与研究 |
| celebrate-v1.png | 完成庆祝 |
| cheer-v1.png | 鼓励 |
| jump-v1.png | 完整站姿；当前角色 64px，可见鞋底留白以 2.472% 位移补偿 |
| father-v1.png | 父亲欢迎形象 |
| mother-v1.png | 母亲欢迎形象 |

生成工具采用内置 image_gen，使用参考图生成新素材，保留透明通道；原照片不进入应用。最终提示词、本地参考记录和素材校验值位于被 Git 忽略的 `private/family-characters/`，其中 `production-prompts.json` 保存提示词。这些记录位于应用目录之外，不提交公开仓库，也不随应用打包。

组件在私图加载成功前显示原图、符号或自定义默认插槽；加载失败则移除私图节点。切换姿势会重置加载状态。没有此目录的公开源码仍可正常显示机器人、活动图标和水果。

## 构建边界

`.gitignore` 只控制 Git，**不会阻止本机静态目录随应用打包**。家庭自用构建可以包含本地素材包；公开预览、APK 或 Release 必须从无该目录的干净工作副本构建，并检查最终产物中不存在 `private-family` PNG。不要把本地家庭 APK 当成公开 APK 发布。

验证包括：真实组件加载失败/成功/姿势切换、缺少私图时的页面显示、手机与平板布局、跳跃长按触控、消消乐交换计数。网页及资源编译通过不代表手机已经安装新版。
