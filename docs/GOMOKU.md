# 五子棋小课堂（1.1.1）

面向孩子和家长的离线棋形入门，入口在首页游戏区、知识口袋游戏区和探索成长。

## 三种玩法

- 学诀窍：8 节短课——五连、一步赢、先防成五、冲四、活四、直活三、攻防兼顾、双向威胁。每课含观察方向、口诀、常见误区和示例棋盘。
- 练一手：每课 2 道原创 9×9 题，覆盖横竖斜变化。程序按真实棋盘判断成五、消除紧急威胁或形成目标棋形，接受多个正确落点。点空位预选，再确认落子。
- 下盘棋：15×15、黑先；小妙离线陪练（入门/稳健）或同机双人。支持解释下一手、参考落点、悔棋及棋谱。陪练采用局部启发式，先自己成五，再阻止对手直接成五；不声称职业棋力或全局最优。

本应用采用家庭自由规则：连续五颗及以上获胜，不设禁手或交换开局。正式比赛有其他规则，不能将本应用允许的黑方双四等同于连珠竞赛合法手。

## 学习与成长

每题区分练习通过和独立通过。查看提示/参考，或当轮尝试错误后改对，仍记录练习完成；重新进入可独立挑战。独立完成 2/8/16 题各获得一枚有限徽章，不按对弈时长或重复胜利刷奖励。

存储键 `miaobang.gomoku-learning.v1`；原数据不存在时从空进度开始，损坏/未知版本记录不覆盖。保存失败保留本次结果，重试成功才显示已保存；待保存时阻止换题。旧六领域徽章兼容保留，七领域共 21 枚、最高 420 点；原等级阈值保留。

## 术语依据及范围

棋形术语核查 [RIF 入门说明](https://www.renju.net/rules/) 和 [RIF 连珠术语定义](https://www.renju.net/rifrules/)。题目、口诀和图形均为项目原创。这里先教连续的直活三，未把跳三或所有复杂三形归为同一简单计数；活四/双向威胁讲解都要求先检查对手是否有更快的直接获胜手。

[RIF 竞赛 Gomoku 规则](https://www.renju.net/gomokurules/)使用恰好五连并有特定开局；本应用的家庭自由变体与该比赛规则不同。后续若学习竞技连珠，需要单独学习禁手和开局，而不是直接复用家庭规则判断。

## 验证与边界

224 项完整规则与页面回归通过。题库测试枚举每个空位，检查所有题目可解、轮次合法、未终局、多解接受、假活三、双威胁及存储失败。真实网页测试包括训练落子、提示后的计分、刷新保留进度、电脑回应、悔棋、双人终局以及手机/平板横竖屏布局。

9×9 为教学局面，不是真实15×15棋谱复原；对弈棋谱暂只在当前页面内保存，离开或新开一局会重置，不宣称已实现永久棋谱库。
