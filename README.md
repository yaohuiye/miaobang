# 妙帮 · Miaobang

本地优先的亲子学习安卓应用，基于 uni-app、Vue 3 和一个小型 UTS/Kotlin 提醒模块。和孩子约定一件小任务，查一条知识，玩一局益智游戏，再一起回顾。

## 功能

- 专注任务：开始、暂停、继续、收尾确认、本机历史；计时到点与任务完成分别记录。
- 每日口算打卡：每组随机 20 题，对应人教版四年级上册口算范围（整万数加减、口算乘法、口算除法与估算）；完成一轮即当天打卡，本机记录正确数、用时和连续天数，并按题型记录首次正确率；错题附分步解法，使用同类新题和隔日验证。
- 知识口袋：723 张卡，英语 473（含外研版三年级起点四年级上、下册 Module 1–10 课本同步词 173）、成语 100、数学 80、科学问答 50、阅读表达 20；搜索、收藏、复习、五题练习。
- 作文范例：对应统编版四年级上册八个习作单元，每单元一篇原创范文加写作提示，供孩子对照学习，不代写。
- 解谜与学习：路线解谜（12 关）、数字搭桥（12 关，后四关四张牌）、安全小侦探（8 场景×3 步判断）、英语三层练习（461 个词，含 173 条课本词，按册/Module 筛选）、光线救援站（6 关）。
- 五子棋训练营：默认进入 48 段连续攻防，孩子需要作出 2–4 次决定，对手实际回应；进攻下到成五、防守化解当前威胁才完成。支持错误反击、回退重想、多解与完成后回看。另保留 8 节棋形手册、160 道单步巩固，以及 15×15 离线陪练和同机双人。采用家庭自由规则（五颗及以上、不设禁手），不混用比赛禁手。
- 六个街机小游戏：扫雷（3 档棋盘与雷密度）、俄罗斯方块（触摸操作、每消 5 行提速）、消消乐（12 关分数/单种与混合水果收集目标）、贪吃蛇（滑动转向、每 3 个苹果提速）、纸翼飞行队（90 秒一局）、跳一跳（3 档、各 10 座岛，进阶档有中心落点目标）；新挑战按难度保存，旧纪录保留。
- 好奇实验室：4 项完整探究（影子比例、浮沉分界、杠杆平衡、水柱射程），由孩子自选至少 3 组对照，选关键证据、解释规律，再对未测条件锁定预测并实际验证。预测可以修正，完成后留下本机研究报告；保留原 13 个自由实验、9 项入门任务及笔记。声音实验附三段自制音调，所有绘图由代码生成。
- 平板布局：手机单列，宽屏首页多列；实验在大屏横屏并排显示，飞机战场保持 2:3 比例。支持安卓横竖屏旋转，实际平板安装与触控效果仍需验收。
- 探索成长：英语、口算、安全、实验、扫雷、跳跃、五子棋七个领域，共 21 枚有限徽章、5 个称号等级；徽章一次奖励 20 点，已获得的不因后来练习失误撤销。
- 成长小花园：记录好事、可选回顾、每天一朵具体鼓励花。
- 旧工具代码：口算生成、汉字查询、古诗查阅。完整保留 2480 条汉字记录；诗词库 127 篇，含补入的四上、四下必背文言文《精卫填海》《王戎不取道旁李》《囊萤夜读》《铁杵成针》和九首小学生必背经典（包含旧数据中的重复项）。

核心业务数据在本机保存，无登录、业务服务端或云同步。游戏独立开放，不以完成作业解锁；计时时长不代表注意力水平，安全故事不代替现实看护。内容按主题整理，不代表完整教材或必考清单。

## 完整离线资源

仓库包含完整汉字、诗词、723 张知识卡，以及原 300 张英语卡对应的 **596 个单词/例句音频文件**（重复文本共用文件）。英语音频已改用 Piper + LJSpeech 合成，不使用 macOS 系统音色；安装后播放无需联网，也不用在手机上安装语音模型。课本同步词（四上、四下 Module 1–10）暂无配套音频，可练词义识别、字母拼装和独立输入；听音练习仅使用确有内置音频的词；课本词表以孩子手里的课本为准。

个人 AppID、签名证书、口令、设备记录和构建产物不随源码发布。素材来源和许可范围见 [素材说明](docs/ASSETS.md)。

## 开始开发

1. 安装 HBuilderX 与 Vue 3 / UTS Android 编译插件，本项目基于 HBuilderX 5.26 开发。
2. 在 HBuilderX 打开 **app/**，而非仓库根目录。
3. 在 manifest.json 中获取自己的 DCloud AppID；用自己的包名与签名打包。
4. 可先运行网页预览。安卓提醒、后台、锁屏和播放器需要真机验证。

本项目没有 package.json；不需要 npm install。用 Node 20+ 在 app/ 执行：

```sh
node --test --test-reporter=spec tests/*.test.mjs
```

当前 254 项测试全部通过，包含离线音频、课本词三层练习、口算变式与隔日验证、安全情境与保存重试、实验任务判定、有限徽章、各游戏规则及页面生命周期回归。规则检查不等于安卓全部功能验证。

### 小游戏触摸体验（1.0.4）

- 俄罗斯方块：按屏幕尺寸放大棋盘，左右滑动移动、轻点旋转、下滑松手落到底；方向按钮可展开。
- 纸翼飞行队：按住任意位置再拖动，飞机按相对距离移动，触摸起点不会使飞机瞬移。
- 消消乐：12 个递增目标的关卡，步数耗尽可以重试；过关解锁下一关，进度保存在本机。
- 跳一跳：按住蓄力、松手起跳，落在中心有加分；连续到达 10 座小岛完成一轮。

消消乐的新进度使用 `miaobang.match-levels.v1`，旧小游戏最高分继续保留。

### 学习与成长更新（1.1.0）

首页及本机记录均可进入“我的探索成长”。进度来自独立练习和有限挑战证据，重复完成同一项不反复发奖；小红花继续由家长为具体尝试送出。详见 [学习改进记录](docs/LEARNING.md)。

### 五子棋学习（1.1.1）

首页游戏区、知识口袋游戏入口和探索成长均可进入“五子棋小课堂”。先读棋形口诀，再在 9×9 局面练一手，最后进入 15×15 对弈。每题分别记录练习与独立完成；提示或当轮试错后可以练会，再重新独立挑战。详见 [五子棋教学说明](docs/GOMOKU.md)。

### 连续攻防与完整探究

五子棋入口默认打开连续训练，原单步题转为可选巩固。训练局面包括连续冲四、跳冲四保留转向点、三方向接力、攻防兼顾，以及横/斜活三防守；提示只给限定搜索已经验证的路线，不声称完整职业棋力。

实验从调旋钮改为“布置条件→记录并观察→选证据解释→预测新条件→实际检验→修正判断”。未记录条件的结果和画面不会提前揭晓；重复完成同一研究更新报告，不重复增加完成数量。两类新进度独立保存，原徽章条件与全部旧记录保留。详见 [五子棋教学说明](docs/GOMOKU.md) 和 [学习改进记录](docs/LEARNING.md)。


### 五子棋题库扩充（1.1.2）

现有 **160 道单步题＋48 段连续攻防**。单步按 8 个主题组织，题数依次为 8/16/24/24/16/16/24/32；连续训练含 46 段进攻续算和 2 段连续防守。页面支持棋形观察、攻防应用、综合挑战筛选，以及进攻/防守选择和分页。原 16 题与原 6 段训练 ID、已完成记录和原徽章条件保留。

新增 144 个单步教学布局包含不同的有效封堵、缺口及对照威胁；扣除比较线后有 78 个目标/约束骨架。新增 42 段连续题的进攻结构均不同，排除旋转、镜像和平移重复，并逐颗验证进攻棋子的必要性。数量表示可练的局面，不表示 208 种独立战术。题库在本机静态加载，断网可练。
